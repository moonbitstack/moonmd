pub fn Document::html(Self, safe? : Bool, xhtml? : Bool) -> String

Render the document as HTML. With safe set, which is the default, raw HTML is escaped and links to dangerous destinations lose their anchor; pass safe=false to write a document that may embed HTML of its own.

xhtml closes the elements that carry nothing (<br />, <hr />, <img />) the way the reference implementation does; pass xhtml=false for the form a document written to HTML5 uses.

pub fn Document::lines(Self) -> Array[LineSpan]

The lines of the source each top level block was read from, counted from one, one entry per block of blocks() and in the same order. Blank lines between blocks belong to neither. A document assembled with of_blocks was not read from text, so its list is empty.

test {
  let document = @moonmd.parse("# One\n\ntwo\n")
  let spans = document.lines()
  assert_eq((spans[0].first, spans[0].last), (1, 1))
  assert_eq((spans[1].first, spans[1].last), (3, 3))
}

pub fn Document::of_blocks(Array[Block], flavor? : Flavor) -> Self

Assemble a document out of blocks, which is what a caller collecting the output of a Stream needs in order to render it. Footnote references are resolved against the definitions in the blocks, so a definition read after the reference that uses it still applies.

pub(all) struct Flavor

What a parser accepts beyond the CommonMark core. The presets commonmark and gfm cover the two dialects this library is asked for; the fields are public so a caller can take one and drop what it does not want.

tables : Bool

Pipe tables.

strikethrough : Bool

~one~ and ~~two~~ strikethrough.

autolinks : Bool

Links written bare, without angle brackets or a destination.

task_lists : Bool

- [ ] and - [x] list items.

tag_filter : Bool

Escape the raw HTML tags that would change the meaning of the page.

footnotes : Bool

[^label] references with their [^label]: definitions.

smart : Bool

Typographic punctuation: "x" and 'x' curl towards the text they wrap, --- and -- become an em and an en dash, and ... becomes an ellipsis. Code spans, raw HTML and destinations are left as written.

breaks : Bool

A line ending inside a paragraph is a hard break, the way a message box reads it, rather than the soft break the specification gives it.

pub struct Stream

A parser that reads a document in pieces. Text that has arrived is parsed again on every call, but only the part that has not been handed out yet, so the work per chunk is proportional to the unfinished tail rather than to the whole document.

pub fn Stream::feed(Self, StringView) -> Array[Block]

Take the next piece of the document and return the blocks it completed.

pub fn Stream::finish(Self) -> Array[Block]

Close the stream and return whatever was still open.

pub fn Stream::new(flavor? : Flavor, defer_links? : Bool) -> Self

Start a stream.

defer_links keeps a block that mentions [ back until the whole document has arrived, because a link reference definition written later still applies to it. With it off such a block is handed out as soon as it closes, at the cost of a forward reference not resolving; the blocks are then the same as a whole parse for any document that defines its labels before using them.
